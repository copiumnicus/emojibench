EMOJIBENCH @ $1

The top models name most random articles in one or two turns, so the benchmark is a ladder on each article:

  1. Rung 1 is the normal game.
  2. Each next rung replays the same article with every emoji used so far banned.
  3. A rung counts if the guesser gets it within 5 turns.
  4. Each model has $1 per article at its API list price. The climb ends when a rung fails or the money runs out.

EMOJIBENCH is an Elo rating with Sonnet 5.5 fixed at 1000. On each article, the model that climbed more rungs wins the head-to-head, and equal rungs is a draw. Comparing within an article means hard articles don't drag anyone's score down. A 200-point gap means winning about 3 articles in 4. Minutes per article is how long a model took to play its ladder on one article, rung after rung. It isn't part of the score, since it depends on the host as much as the model, but it shows what a score costs in waiting.

How a game works

  1. The harness pulls an article from Wikipedia's random-article button. Most are obscure: small rivers, minor politicians, single ant species.
  2. The explainer sees the title and summary and writes a message. A filter deletes everything that is not a standard emoji, including emoji that contain letters or digits like 🅰️ 🆗 1️⃣ ℹ️, so spelling is impossible. Flags are allowed.
  3. The guesser reads the emoji and replies in plain text: questions, theories, and at most one guess per turn.
  4. A separate model judges each guess against the title. Alternate names and missing accents count; a related topic does not.
  5. The game ends on a correct guess or after 30 turns.

What's next

  • More models, including other labs. A new model climbs the same 20 ladders once and slots into the rating; anyone can add one with a pull request.
  • More articles, 50 to 100, with an uncertainty range next to each rating.
  • A tie-break that gives the head-to-head to the cheaper model when both climb the same number of rungs.
